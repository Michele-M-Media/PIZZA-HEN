PIZZA HEN v1.0 — MULTILANGUAGE RELEASE

BASELINE
- Runtime base: R7.6.3 HIDDEN LEGACY TOOLBOX HOSTS RESTORE (hardware-PASS, user confirmed).
- This release adds only the multilingual presentation/locale handoff layer plus release naming/tests.
- No service, KStuff, ShadowMount, scanner, Payload Manager, Package Installer, Fan, Klog, Overlay, Cheats or Debug routing logic is intentionally changed.

LANGUAGE POLICY
- PIZZA HEN follows the PS5 WebView/OS locale automatically.
- No manual PIZZA HEN language selector.
- Locale is normalized to one of the 31 PS5 console languages and persisted to /data and /user/data runtime locale files.
- Debug Services reads the persisted locale before generating native ShellUI XML.
- Arabic WebView UI uses RTL direction.
- Unsupported/unrecognized locale falls back to en-US.
