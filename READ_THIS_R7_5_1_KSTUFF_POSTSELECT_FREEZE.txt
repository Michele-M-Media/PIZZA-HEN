PIZZA HEN R7.5.1 - KSTUFF POST-SELECTION SHELLUI PRELOAD ROLLBACK

Hardware symptom under investigation:
- PS5 freezes immediately after selecting KStuff.

Source-grounded delta:
- R7.2 hardware-PASS bootstrapper/source/main.cpp SHA256 is identical to R7.5.
- Therefore the KStuff selector, selected-engine spawn, readiness gate, dual Media tile registration,
  ShadowMountPlus/FTP/ps5debug ordering in bootstrapper are unchanged between R7.2 and R7.5.
- R7.3 introduced an automatic daemon startup call to cmd_ensure_game_options_service_runtime().
- That call pauses/resumes KStuff by directly toggling PS5/PS4 sysentvec state and injects shellui.elf
  into ShellUI during startup.
- R7.2 hardware-PASS did not perform this startup ShellUI injection.

R7.5.1 change:
- Disable ONLY the automatic startup call to cmd_ensure_game_options_service_runtime().
- Keep the function and R7.5 source intact for future explicitly gated/on-demand use.
- Keep R7.3/R7.4/R7.5 Toolbox, KStuff selector, dual Media tiles, ShadowMountPlus, FTP, ps5debug,
  PHU/PIZZA overlay assets, Payload Repository, KStuff Toggle and Debug Services changes intact.
- Modern Toolbox Cheats remains present. The Game Options resident Cheats hook is not preloaded at boot.

This is a source-grounded isolation repair. Static validation is not a hardware PASS.
