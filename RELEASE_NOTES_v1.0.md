# PIZZA HEN v1.0 🍕🐓

First public v1.0 release checkpoint of **PIZZA HEN** by Michele Media.

## Main features

- PIZZA HEN Toolbox
- KStuff Lite 1.10 / KStuff DR 1.2 selector
- ShadowMountPlus 1.6beta16 baseline
- CheatRunner 0.17 integration
- DPIv2 package installer path
- 12.20+ DPIv2 MetaInfo repair
- FTP and ps5debug-NG service chain
- multilingual PS5-locale UI
- Multi-SDK build discovery
- multi-firmware ShellCore / Debug Services compatibility work

## Hardware validation

The DPIv2 12.x path in this checkpoint is hardware-confirmed on PS5 firmware:

**12.20 through 12.70**

## Experimental note

The Game Options CheatRunner shortcut included in this source checkpoint is experimental. It is not required for the main Toolbox/CheatRunner workflow and is not part of the v1.0 hardware-compatibility claim.

## Build

Windows + WSL:

`RUN_BUILD_R713_CHEATRUNNER_GAME_OPTIONS_SHORTCUT.bat`

Linux / WSL:

`./RUN_BUILD_PIZZA_HEN.sh`
