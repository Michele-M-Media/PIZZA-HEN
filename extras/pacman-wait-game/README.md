# Pac-Man Wait Game

Standalone fullscreen browser mini-game intended as a waiting-screen module.

- Language: English
- No PIZZA HEN branding
- Score, level, lives, pellets, power pellets, ghosts, pause, game over
- Keyboard: arrows or WASD; Enter starts/continues; Space pauses/resumes
- No external assets or network dependencies
- No changes to the main project branch

Open `index.html` in a browser to run it.

This branch keeps the game isolated from the project runtime so it can be tested safely before any separate integration work.
