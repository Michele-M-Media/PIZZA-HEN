# PIZZA HEN v0.1 Beta 🍕🐓

First public beta of **PIZZA HEN**, an experimental PS5 homebrew environment maintained by Michele Media.

## Included
- PIZZA HEN Toolbox Media tile
- KStuff Lite 1.09 / KStuff DR 1.2 graphical selector
- single KStuff engine per boot
- pristine ShadowMountPlus 1.6beta16 runtime integration
- automatic FTP
- automatic ps5debug-NG
- direct Itemzflow Game Manager integration
- unified cheat repositories
- PIZZA HEN Game Overlay defaults
- Multi-SDK build system
- beta App Plugin Manager with per-title / default autoload lifecycle

## Important
This is a **pre-release**. The newest App Plugin Manager lifecycle is experimental and will continue to be improved.

Itemzflow is not bundled in the Git repository and must be installed separately from its official project.

See `README.md`, `README_IT.md`, `CREDITS.md`, `THIRD_PARTY.md` and `CHANGELOG.md` for details.
