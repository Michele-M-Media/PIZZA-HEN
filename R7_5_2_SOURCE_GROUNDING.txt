   send_shell_control(), gated by BREW_PIZZAHEN_SHELL_SERVICE = 0x09000016.
   The current daemon command enum/handler has no such command. Therefore
   common Toolbox settings returned failure before their config write.
2. toolbox_api defined BREW_TESTKIT_CHECK as 0x0900000F, while the current
   Source Code/include/msg.hpp enum resolves BREW_TESTKIT_CHECK to 0x09000010.

  config_set_numeric(key,value) -> reload daemon settings on success.
- Corrected BREW_TESTKIT_CHECK to 0x09000010 to match the current enum.
