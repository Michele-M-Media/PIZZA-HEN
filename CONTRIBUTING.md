# Contributing

1. Keep source-built integrations Multi-SDK / capability-based.
2. Do not hard-code one Payload SDK release directory.
3. Do not modify frozen ShadowMount runtime logic unless the project explicitly changes that baseline.
4. Preserve the two-choice KStuff selector and single-engine-per-boot rule.
5. Preserve upstream copyright and license notices.
6. Add or update a regression test for behavior changes.
7. Clearly label unverified hardware behavior as experimental.
